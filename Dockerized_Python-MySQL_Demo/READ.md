## Project Description

Developed a containerized **Python–MySQL ETL demo application** using **Docker** and **Docker Compose**.

### Key Features
- Automated MySQL database initialization using mounted SQL scripts through Docker volumes.
- Enabled automatic table creation and seed data loading during container startup.
- Implemented inter-container communication between Python and MySQL services using Docker networking.
- Executed SQL queries using Python MySQL Connector.

### Technologies Used
- Python
- MySQL
- Docker
- Docker Compose
- SQL
